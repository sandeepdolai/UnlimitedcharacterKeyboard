# Pasteboard Keyboard Android project

Open this folder in Android Studio. The project uses JDK 17, Android Gradle Plugin 8.10.1, Kotlin 2.1.20 and compileSdk 36.

To create a debug APK in Android Studio, choose Build > Build Bundle(s) / APK(s) > Build APK(s). The output is app/build/outputs/apk/debug/app-debug.apk.
